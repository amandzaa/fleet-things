# Fleet Things

A modern e-commerce web application built with React, TypeScript, and Vite.

## Features

- Product browsing and detailed product views
- Shopping cart functionality with real-time updates
- User authentication (login/register)
- Protected routes for authenticated users
- Responsive navigation with cart badge
- Product slideshow component
- Profile management

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Context API for state management

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/amandzaa/fleet-things.git
```

2. Install dependencies:

```bash
cd fleet-things
npm install
```

3. Start the development server:

```bash
npm run dev
```

The application will be available at `http://localhost:5173`

## Project Structure

- `/src/components` - Reusable UI components
- `/src/pages` - Main application pages
- `/src/context` - React Context providers
- `/src/authentification` - Authentication-related components
- `/src/types` - TypeScript type definitions
- `/src/routing` - Route protection and configuration

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run lint` - Run ESLint
- `npm run preview` - Preview production build locally
